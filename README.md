# Interface Elevation Signs

The business website for **Interface Elevation Signs**, a company with over 27 years in facade elevation, structural glazing, ACP cladding, LED displays and signage across India. Built as client work.

## Sections

Animated intro, hero, about, services, horizontally scrolling project showcase, clients, why choose us, and a contact form.

## Stack

- Next.js 14 (App Router) and React 18
- Tailwind CSS
- GSAP for scroll and entrance animations
- `screenshot_website.py` captures full-page screenshots for client review

## Running it

```bash
npm install
npm run dev       # http://localhost:3000
npm run build && npm start
```
